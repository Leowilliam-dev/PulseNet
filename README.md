# PulseNet

PulseNet is a phone-first Android network analyzer designed to measure connection quality for gaming, streaming, video calls, and everyday internet use.

## Features

- Latency measurement
- Jitter measurement
- Packet loss
- Connection stability
- Download and upload testing
- Gaming readiness
- eFootball readiness
- COD Mobile readiness
- Streaming readiness
- Video-call readiness

## Goal

Provide a simple and useful way to understand whether an internet connection is suitable for real-time applications.
